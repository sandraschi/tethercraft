# Asset attribution

Every non-code asset in this repository is listed here with its author, source and licence. `cargo xtask assets` (part of `cargo xtask ci`) fails if an asset file is missing from this table.

**Policy (mandatory):** TetherCraft contains no proprietary vendor iconography, images, templates, themes, sounds, fonts or other assets. Every asset is original work by TetherCraft contributors or openly licensed material on the storytold/craft-contrib licence allowlist.
