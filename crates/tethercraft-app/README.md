# `tethercraft-app` (L2/L3 CLI & egui Controller Window)

Unified human CLI (`status`, `id`, `peers`, `connect`, `host`, `serve`, `book`, `audit`, `files`, `sync`, `tunnel`, `gui`, `server`, etc. with `--json`) plus the native `egui` controller window with peer sidebar, live frame stream, always-visible **End session** button, `Ctrl+Wheel` zoom, and R1 install gate.

```powershell
cargo run -p tethercraft-app -- status --json
```
